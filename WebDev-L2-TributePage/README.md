# Ahmed Zewail – Tribute Page

A modern and elegant responsive tribute website celebrating the life,
scientific achievements, and legacy of Ahmed H. Zewail.

## Project Objective

The objective of this project is to create a responsive tribute page
using HTML, CSS, and JavaScript.

The website presents the biography, scientific contributions,
major milestones, and Nobel Prize achievement of Ahmed Zewail.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts
- Wikimedia Commons

## Main Features

- Modern and elegant user interface.
- Responsive design for desktop and mobile devices.
- Sticky navigation bar.
- Mobile navigation menu.
- Biography and historical information.
- Femtochemistry discovery section.
- Career and achievement timeline.
- Nobel Prize information.
- Scroll reveal animations.
- External reference links.
