# TaskHub – To-Do Web App

A responsive task management application built for the **Oasis Infobyte Web Development & Designing Internship – Level 2**.

## Features
- Add, edit, and delete tasks
- Mark tasks as pending or completed
- High, medium, and low priority
- Optional due dates
- All, pending, and completed filters
- Completion progress indicator
- Clear all completed tasks
- Dark and light themes
- Local Storage persistence
- Responsive desktop and mobile layout
- Safe task rendering with `textContent`

## Technologies
HTML5, CSS3, Vanilla JavaScript, and Browser Local Storage.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` with Live Server, or open it directly in a browser.
3. Add tasks and refresh the page to verify that tasks remain saved.
