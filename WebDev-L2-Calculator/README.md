# Calculator – OIBSIP Level 2

A responsive calculator built as part of the **Oasis Infobyte Web Development & Designing Internship – Level 2**.

## Features

- Addition, subtraction, multiplication, and division
- Chained calculations (for example: `12 + 5 × 2`)
- Decimal numbers and percentage
- Positive/negative toggle
- Delete and clear functions
- Division-by-zero error handling
- Keyboard support
- Responsive layout for desktop and mobile

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

1. Download or clone this repository.
2. Open the `WebDev-L2-Calculator` folder.
3. Open `index.html` in your browser.

No installation or build tools are required.

## Test cases

| Test | Input | Expected result |
|---|---|---|
| Addition | `12 + 8 =` | `20` |
| Subtraction | `15 − 6 =` | `9` |
| Multiplication | `7 × 4 =` | `28` |
| Division | `20 ÷ 5 =` | `4` |
| Chaining | `10 + 5 + 2 =` | `17` |
| Division by zero | `8 ÷ 0 =` | `Cannot divide by zero` |
